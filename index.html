Post-Quantum Cryptography Polynomial Multiplication FPGA NTT / INTT CRYSTALS-Dilithium

Hardware Design and FPGA Implementation of a Polynomial Multiplication Accelerator for CRYSTALS-Dilithium

Authors: Linh Tran, Hoang Anh, and Hieu Le

This work presents a scalable FPGA accelerator for CRYSTALS-Dilithium polynomial multiplication with n = 256 and q = 8380417. The accelerator executes the complete polynomial multiplication flow: NTT(A), NTT(B), pointwise Montgomery multiplication, INTT, and final scaling. Three scalable architectures, 4BU, 8BU, and 16BU, share the same control template, memory-banking policy, twiddle-factor access pattern, arithmetic datapath, and verification methodology.

Parameter Set n = 256 • q = 8380417
Architecture Family 4BU • 8BU • 16BU
Core Datapath Unified CT / GS Butterfly
Memory Architecture Schedule-ROM • Conflict-Free Banking

Overall PMUL Accelerator Architecture

The complete hardware datapath integrates the control FSM, schedule ROM, twiddle-factor ROM, banked BRAM A/B, the parallel butterfly-unit array, and pipeline-aligned writeback path.

Fig. 11. Overall PMUL accelerator.

Key Contributions

  • Complete Dilithium polynomial multiplication flow rather than an isolated NTT core.
  • Scalable 4BU, 8BU, and 16BU architectures using a common scheduler, memory organization and butterfly datapath.
  • Unified datapath supporting Cooley–Tukey NTT, Gentleman–Sande INTT, pointwise multiplication and final scaling.
  • Montgomery multiplication with reduction-constant products implemented by shift/add/sub networks.
  • Schedule-ROM address generation and banked polynomial memories with conflict-free issue metadata.
  • Layered verification up to the complete 256-coefficient polynomial multiplication result.

FPGA Results

On Intel Cyclone V, the 4BU, 8BU and 16BU architectures complete one end-to-end polynomial multiplication in 1483, 1035 and 811 cycles, respectively. Their measured throughputs are 84.73, 107.55 and 131.99 thousand polynomial multiplications per second. The 16BU implementation reaches 107.04 MHz on Cyclone V and completes one multiplication in 7.577 µs.

4BU: 1483 cycles 8BU: 1035 cycles 16BU: 811 cycles 16BU: 131.99k PMUL/s
